# เฟสที่ 5: การปล่อยโค้ด #

นี่คือเอกสารที่อธิบายวิธี_ปล่อยโค้ด_สคริปต์ `.mm`

## แนวคิดที่เป็นประโยชน์ ##

**`generator` คืออะไร?**
`generator` ใช้ท่องตัวแทนตรรกะบางอย่างในเชิงนามธรรม
จากนั้นเรียก `emitter` เมื่อเหมาะสม เพื่อปล่อยโค้ดในตัวแทนเป้าหมายจริง

**`emitter` คืออะไร?**
`emitter` เปิด API ที่เรียกได้เพื่อปล่อยโค้ดในตัวแทนเป้าหมาย
จะมี emitter มากเท่ากับจำนวนตัวแทนเป้าหมายที่ภาษารองรับ

## กลยุทธ์การอินเจกต์ ##

โค้ดที่ถูกปล่อย และวิธีการปล่อย ขึ้นอยู่กับกลยุทธ์การอินเจกต์ที่ผู้ใช้ระบุ

ปัจจุบันมีกลยุทธ์การอินเจกต์ที่รองรับสองแบบ:
1. [การเขียนไบต์โค้ดใหม่](./rewriting.md)
2. การเชื่อมต่อกับ[เอนจิน](wei.md)
