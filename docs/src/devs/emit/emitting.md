# เฟสที่ 5: การปล่อยโค้ด #

นี่คือเอกสารที่อธิบายวิธี*ปล่อยโค้ด*สคริปต์ `.mm`

## แนวคิดที่เป็นประโยชน์ ##

**`generator` คืออะไร?**
`generator` ใช้ท่องตัวแทนของตรรกะบางอย่างในเชิงนามธรรม
จากนั้นจึงเรียก `emitter` เมื่อเหมาะสม เพื่อปล่อยโค้ดในตัวแทนเป้าหมายจริง

**`emitter` คืออะไร?**
`emitter` เปิด API ที่สามารถเรียกได้เพื่อปล่อยโค้ดในตัวแทนเป้าหมาย
โดยจะมี emitter มากเท่ากับจำนวนตัวแทนเป้าหมายที่ภาษารองรับ

## กลยุทธ์การอินเจกต์ ##

โค้ดที่ถูกปล่อย และวิธีการปล่อย ขึ้นอยู่กับกลยุทธ์การอินเจกต์ที่ผู้ใช้ระบุ
