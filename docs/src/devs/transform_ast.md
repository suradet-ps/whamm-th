# เฟสที่ 3: การแปลง AST #

ขั้นตอนนี้ทำโดยก่อนอื่นเก็บเมตาดาต้าเกี่ยวกับแต่ละโพรบในการท่อง AST ผ่าน [`MetadataCollector`]
ตัวเก็บนี้ติดตามสิ่งต่อไปนี้ (รายการนี้อาจขยายในอนาคต):
- ฟังก์ชันไลบรารีของผู้ใช้ที่ถูกใช้จริงในสคริปต์
- ฟังก์ชันที่ผูกไว้ (bound functions) ที่ถูกใช้จริงในสคริปต์
- ชนิดข้อมูลแต่ละชนิดที่ต้องถูกระบายตอน report
- สตริงที่จำเป็นต้องมีเพื่อให้สคริปต์ทำงานได้
- ว่าโพรบใดมีสถานะที่ต้องเริ่มต้นหรือไม่

การติดตามสถานะทั้งหมดนี้ช่วยให้ปล่อยโค้ดได้ดีขึ้นในแบ็กเอนด์ของคอมไพเลอร์
มันยังสรุปตัวแปรที่ผูกแบบสแตติกและพลวัตของแต่ละโพรบด้วย
รายการนี้ถูกใช้ในการเขียนไบต์โค้ดใหม่เพื่อนิยามข้อมูลสแตติกที่จำเป็นตอนคอมไพล์ไทม์ และเพื่อปล่อยโค้ดที่จำเป็นสำหรับนิยามข้อมูลพลวัตตอนรันไทม์
สำหรับแบ็กเอนด์ `wei` ตัวแปรที่ผูกแต่ละตัวจะถูกขอจากเอนจิน เพื่อให้เอนจินส่งค่าของมันให้ฟังก์ชันคอลแบ็กของโพรบหรือเพรดิเคต
