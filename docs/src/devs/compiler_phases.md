# สี่เฟสของการคอมไพล์ #

ก่อนอื่น ความหมายของคำว่า "การคอมไพล์" ขึ้นอยู่กับกลยุทธ์การอินเจกต์ที่เลือกไว้

สำหรับ**การเขียนไบต์โค้ดใหม่** การคอมไพล์หมายถึงการสร้างไบต์โค้ดของแอปพลิเคชันรูปแบบใหม่ที่*ทำ instrumentation แล้ว*

สำหรับ**การรองรับเอนจินโดยตรง** การคอมไพล์หมายถึงการคอมไพล์สคริปต์ `.mm` ให้เป็นโมดูล Wasm ใหม่ที่เชื่อมต่อกับเอนจินเพื่อทำ instrumentation กับโปรแกรมแบบพลวัต
เมื่อใช้กลยุทธ์นี้ โปรแกรมต้นฉบับ*ไม่ถูกแตะต้อง* **และ** *ไม่ถูกจัดหา*ให้กับคอมไพเลอร์

สามเฟสแรกของการคอมไพล์ `Whamm` เหมือนกันทั้งสองกลยุทธ์
ส่วนเฟส `translate` และ `emit` จะแตกต่างกันไปตามกลยุทธ์การอินเจกต์
ทั้งนี้เพราะ "การปล่อยโค้ด" สำหรับ**การเขียนไบต์โค้ดใหม่**หมายถึงการใช้ไลบรารี `wirm` เพื่อแทรกคำสั่งใหม่เข้าไปในโปรแกรม
ในขณะที่ "การปล่อยโค้ด" สำหรับ**การรองรับเอนจินโดยตรง**หมายถึงการปล่อยโมดูล Wasm ที่เข้ารหัส*ว่าจะทำ instrumentation ที่ไหน*และคอลแบ็กที่จะแนบ ณ จุดที่โพรบ โดยเชื่อมต่อกับเอนจินตอนรันไทม์ของแอปพลิเคชัน
