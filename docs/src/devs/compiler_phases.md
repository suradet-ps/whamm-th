# สี่เฟสของการคอมไพล์ #

ก่อนอื่น ความหมายของคำว่า "การคอมไพล์" ขึ้นอยู่กับกลยุทธ์การอินเจกต์ที่เลือก

สำหรับ**การเขียนไบต์โค้ดใหม่** การคอมไพล์หมายถึงการสร้างไบต์โค้ดของแอปพลิเคชันรูปแบบใหม่ที่_ทำ instrumentation แล้ว_

สำหรับ**การรองรับเอนจินโดยตรง** การคอมไพล์หมายถึงการคอมไพล์สคริปต์ `.mm` เป็นโมดูล Wasm ใหม่ที่เชื่อมต่อกับเอนจินเพื่อทำ instrumentation กับโปรแกรมแบบพลวัต
โปรแกรมต้นฉบับ_ไม่ถูกแตะต้อง_**และ**_ไม่ถูกจัดหา_เมื่อใช้กลยุทธ์นี้

สามเฟสแรกของการคอมไพล์ `Whamm` เหมือนกันทั้งสองกลยุทธ์
เฟส `translate` และ `emit` แตกต่างกันตามกลยุทธ์การอินเจกต์
เพราะ "การปล่อยโค้ด" สำหรับ**การเขียนไบต์โค้ดใหม่**หมายถึงการใช้ไลบรารี `wirm` เพื่อแทรกคำสั่งใหม่เข้าไปในโปรแกรม
ในขณะที่ "การปล่อยโค้ด" สำหรับ**การรองรับเอนจินโดยตรง**หมายถึงการปล่อยโมดูล Wasm ที่เข้ารหัส_ว่าจะทำ instrumentation ที่ไหน_และคอลแบ็กที่จะแนบ ณ จุดที่โพรบ โดยเชื่อมต่อกับเอนจินตอนรันไทม์ของแอปพลิเคชัน
