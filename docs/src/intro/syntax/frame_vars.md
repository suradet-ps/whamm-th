# ตัวแปร `frame` #

หมายเหตุ: ฟังก์ชันนี้ยังไม่ถูกพัฒนาเสร็จสมบูรณ์! จะมีเอกสารเพิ่มเติมหลังการพัฒนา!

หากตัวแปรถูกทำเครื่องหมายเป็น `frame` อินสแตนซ์เดียวของตัวแปรนี้ ตัวแปรเองจะถูกเก็บไว้บนเฟรมที่ทำงานอยู่ของฟังก์ชัน
ดังนั้นตัวแปรจึงอยู่ในสโคปของทุกโพรบในเฟรมที่ทำงานอยู่นั้น
ค่าของตัวแปรนี้จะคงที่ตลอดการเข้าถึงของโพรบขณะที่เฟรมของฟังก์ชันหนึ่งๆ ทำงานอยู่

ใช้เก็บข้อมูลสำหรับอีเวนต์ที่โพรบ_ระหว่างการทำงานของฟังก์ชันหนึ่งๆ_ได้

ตัวอย่าง:
```
// Tracks all of the runtimes of each function invocation across program execution.
use time;
wasm:func:entry {
    frame var start: u32;
    start = time.now();
}
wasm:func:exit {
    frame var start: u32;
    unshared var elapsed: vec<u32>;
    elapsed.push(time.now() - start);
}
```
