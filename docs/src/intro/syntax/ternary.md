# นิพจน์เทอร์นารี #

`Whamm` รองรับนิพจน์ "เงื่อนไข" รูปแบบหนึ่งที่เลือกค่าระหว่างสองค่าตามเงื่อนไข
ไวยากรณ์เป็นไปตาม C, C++ และ Java ซึ่งใช้ `? :`

```
// with declared types
var a: i32;
a = 1 > 0 ? 16 : 27; // == 16
a = 1 < 0 ? 17 : 29; // == 29
```

## การประเมินแบบลัดวงจร ##

นิพจน์เทอร์นารีจะประเมินเฉพาะกิ่งที่ตรงกับค่าของเงื่อนไขเท่านั้น
พูดอีกอย่างคือ มันลัดวงจร
