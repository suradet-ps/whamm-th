# ขอบเขตชนิด #

ออปโคดของ Wasm บางตัว เช่น `local.set` มีอาร์กิวเมนต์แบบหลายรูปแบบ (polymorphic)
ผู้ใช้สามารถกำหนดเงื่อนไขเพิ่มเติมให้กับการแมตช์ตำแหน่งโพรบดังกล่าวตามชนิดได้ด้วย_ขอบเขตชนิด (type bound)_

ในตอนนี้ วิธีนี้ยังช่วยเลี่ยงความจำเป็นในการทำ polymorphism ใน `Whamm`
โดยผู้ใช้ต้องสร้างโพรบแบบ_ขอบเขตชนิด_หนึ่งตัวต่อชนิดที่เป็นไปได้แต่ละชนิด

ตัวอย่างการใช้ขอบเขตชนิดมีดังนี้:
```
wasm:opcode:call(arg0: i32):before {
    report unshared var all_arg0s: map<i32, i32>;
    all_arg0s[arg0]++;
}
```
