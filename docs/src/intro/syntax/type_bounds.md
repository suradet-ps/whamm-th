# ขอบเขตชนิด #

ออปโค้ดของ Wasm บางตัว เช่น `local.set` มีอาร์กิวเมนต์แบบ polymorphic
ผู้ใช้สามารถกำหนดเงื่อนไขเพิ่มเติมกับการแมตช์ตำแหน่งโพรบดังกล่าวตามชนิดได้ด้วย_ขอบเขตชนิด_

ในตอนนี้ วิธีนี้ยังเลี่ยงความจำเป็นในการทำ polymorphism ใน `Whamm`
ทำให้ผู้ใช้ต้องสร้างโพรบแบบ_ขอบเขตชนิด_หนึ่งตัวต่อชนิดที่เป็นไปได้

นี่คือตัวอย่างการใช้ขอบเขตชนิด:
```
wasm:opcode:call(arg0: i32):before {
    report unshared var all_arg0s: map<i32, i32>;
    all_arg0s[arg0]++;
}
```
