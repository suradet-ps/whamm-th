# ทูเพิล #

ทูเพิล (tuple) เป็นวิธีที่รวดเร็วและง่ายดายในการรวมค่าตั้งแต่หนึ่งค่าขึ้นไปให้เป็นค่าเชิงประกอบ

```

var a: (i32, i32);
a = (0, 1);

var b: (bool, i32);
b = (true, 78);
```

## การเข้าถึงสมาชิก ##

สมาชิกของทูเพิลเข้าถึงได้เสมือนเป็นฟิลด์ของค่าทูเพิล
แทนที่จะใช้ชื่อฟิลด์ สมาชิกจะถูกอ้างด้วยเลขจำนวนเต็ม เริ่มนับจาก `0`

```
// tuple members are accessed with '.' and numbered from 0
var a: (bool, i32);
a = (true, 1);

var b: bool;
b = a.0;    // == true

var c: i32;
c = a.1;    // == 1

var d: (i32, (i32, i32));
d = (1, (12, 13));

var e: i32;
e = d.1.0;  // == 12
```
