# ชนิดพื้นฐาน #

`Whamm` มีชนิดพื้นฐานชุดเล็กๆ ที่มีประโยชน์ต่อการคำนวณทางเลขคณิตและการแทนข้อมูล

## บูลีน ##

ด้วยค่าเพียงสองค่า คือ `true` และ `false` บูลีนใน `Whamm` ใช้ชนิด `bool`

```
var x: bool; // default == false
x = true;
x = false;
```

## จำนวนเต็ม ##

ขณะนี้ `Whamm` รองรับชนิดต่อไปนี้:

| ชนิด  | บิต | คำอธิบาย                    | ค่าต่ำสุด                           | ค่าสูงสุด                                          |
|-------|------|-----------------------------|-------------------------------------|----------------------------------------------------|
| `u8`  | 8    | ค่า_ไม่เป็นเครื่องหมาย_     | `0`                                 | `255` (เท่ากับ `2^8 - 1`)                          |
| `i8`  | 8    | ค่า_มีเครื่องหมาย_          | `-128` (เท่ากับ `-2^7`)             | `127` (เท่ากับ `2^7 - 1`)                          |
| `u16` | 16   | ค่า_ไม่เป็นเครื่องหมาย_     | `0`                                 | `65_535` (เท่ากับ `2^16 - 1`)                      |
| `i16` | 16   | ค่า_มีเครื่องหมาย_          | `-32_768` (เท่ากับ `-2^15`)         | `32_767` (เท่ากับ `2^15 - 1`)                      |
| `u32` | 32   | ค่า_ไม่เป็นเครื่องหมาย_     | `0`                                 | `4_294_967_295` (เท่ากับ `2^32 - 1`)               |
| `i32` | 32   | ค่า_มีเครื่องหมาย_          | `-2_147_483_648` (เท่ากับ `-2^31`)  | `2_147_483_647` (เท่ากับ `2^31 - 1`)               |
| `f32` | 32   | ค่า_จุดลอยตัว_              | `-3.40282347E+38`                   | `3.40282347E+38`                                   |
| `u64` | 64   | ค่า_ไม่เป็นเครื่องหมาย_     | `0`                                 | `4_294_967_295` (เท่ากับ `2^32 - 1`)               |
| `i64` | 64   | ค่า_มีเครื่องหมาย_          | `-2_147_483_648` (เท่ากับ `-2^31`)  | `18_446_744_073_709_551_615` (เท่ากับ `2^63 - 1`)  |
| `f64` | 64   | ค่า_จุดลอยตัว_              | `-1.7976931348623157E+308`          | `1.7976931348623157E+308`                          |

```
// with declared types
var d: i32; // default == 0
d = 0;
d = 9993;
d = -42;
```
