# ภาษา #

`Whamm` เปิดทางให้นักพัฒนาเครื่องมือแสดง instrumentation ในรูปของ*อีเวนต์*ในโปรแกรมและ*การกระทำที่มีเพรดิเคต*ที่สอดคล้องกัน
กล่าวคือ "เมื่อ*อีเวนต์นี้*เกิดขึ้นระหว่างการทำงานของโปรแกรม ให้ลงมือทำ*การกระทำเหล่านี้*หาก*เพรดิเคต*นี้ (หรือเงื่อนไข) ประเมินเป็น `true`"
นามธรรมเช่นนี้ทำให้ได้ไวยากรณ์ระดับสูงที่เข้าใจง่าย และกำหนดเป้าหมายอีเวนต์ได้ที่ความละเอียดต่างๆ กันในโปรแกรมเป้าหมาย

อ่านต่อไปเพื่อดูภาพรวมของไวยากรณ์และความหมายของภาษา

## แนวคิดของภาษา ##
- [ตัวแปร](syntax/variables.md) ใช้สำหรับเก็บข้อมูล
- [การดำเนินการเชิงตรรกะ](syntax/logop.md) ใช้รวมนิพจน์บูลีนหลายนิพจน์เข้าด้วยกัน
- [นิพจน์เทอร์นารี](syntax/ternary.md) ช่วยกำหนดค่าตัวแปรแบบมีเงื่อนไขได้อย่างกระชับ
- [ชนิดพื้นฐาน](syntax/primitives.md) ได้แก่ ตัวเลข บูลีน และสตริง
- [การดำเนินการทางเลขคณิต](syntax/arith.md) รูปแบบต่างๆ ใช้ได้กับตัวเลข
- [สตริง](syntax/strings.md) เป็นหัวใจของการจัดการข้อความและอื่นๆ
- [ทูเพิล](syntax/tuples.md) ช่วยให้ใช้หลายค่าตรงที่ปกติคาดว่าจะมีค่าเดียว
- [แมป](syntax/maps.md) เป็นหัวใจของการเก็บข้อมูลปริมาณมาก แต่ถูกนำไปใช้ต่างออกไปพอสมควรใน `Whamm`
- นิยาม[ฟังก์ชัน](syntax/functions.md) ช่วยให้ใช้โค้ดบางส่วนซ้ำได้
- [คำสั่งเงื่อนไข](syntax/conditionals.md) คือคำสั่ง if/else/elif สำหรับควบคุมโฟลว์อย่างง่าย
- [ขอบเขตชนิด](syntax/type_bounds.md) ใช้จัดการออปโค้ดที่มีหลายรูปแบบ (polymorphic)
- `Whamm` ยังมีฟีเจอร์ที่ช่วยเสริมความสามารถในการแสดง instrumentation
  - ตัวแปร [Report](syntax/report_vars.md) เป็นหัวใจของการระบายข้อมูลเชิงพลวัตที่ instrumentation เก็บรวบรวมระหว่างการรันแอปพลิเคชัน
  - ตัวแปร [Unshared](syntax/unshared_vars.md) สร้างอินสแตนซ์ของตัวแปรให้ทุกจุดที่แมตช์ของโพรบ โดยค่ายังคงอยู่ข้ามการมาเยือนจุดนั้น
  - ตัวแปร [Shared](syntax/shared_vars.md) สร้างอินสแตนซ์ของตัวแปรที่ทุกจุดที่แมตช์ของโพรบ*ใช้ร่วมกัน*
  - ตัวแปร [Frame](syntax/frame_vars.md) สร้างอินสแตนซ์ของตัวแปรที่ถูกเก็บไว้บนเฟรมที่ทำงานอยู่ของฟังก์ชัน
- และสุดท้าย [โพรบ](syntax/probes.md) ใช้แสดง instrumentation
- ไวยากรณ์ทั้งหมดนี้ใช้เขียน[สคริปต์](syntax/scripts.md) `Whamm`
