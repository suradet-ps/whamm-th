# ภาษา #

`Whamm` เปิดทางให้นักพัฒนาเครื่องมือแสดง instrumentation ในรูปของ_อีเวนต์_ในโปรแกรมและ_การกระทำที่มีเพรดิเคต_ที่สอดคล้องกัน
"เมื่อ_อีเวนต์นี้_เกิดขึ้นระหว่างการทำงานของโปรแกรม ให้ทำ_การกระทำเหล่านี้_ถ้า_เพรดิเคต_นี้ (หรือเงื่อนไข) ประเมินเป็น `true`"
นามธรรมนี้ให้ไวยากรณ์ระดับสูงที่เข้าใจง่าย ซึ่งกำหนดเป้าหมายอีเวนต์ได้ที่ความละเอียดต่างๆ ในโปรแกรมเป้าหมาย

อ่านต่อเพื่อดูภาพรวมของไวยากรณ์และความหมายของภาษา

## แนวคิดของภาษา ##
- [ตัวแปร](syntax/variables.md) ใช้เก็บข้อมูล
- [การดำเนินการเชิงตรรกะ](syntax/logop.md) ใช้รวมนิพจน์บูลีน
- [นิพจน์เทอร์นารี](syntax/ternary.md) ใช้กำหนดค่าตัวแปรแบบมีเงื่อนไขได้อย่างกระชับ
- [ชนิดพื้นฐาน](syntax/primitives.md) ได้แก่ ตัวเลข บูลีน และสตริง
- [การดำเนินการทางเลขคณิต](syntax/arith.md) ต่างๆ ใช้กับตัวเลขได้
- [สตริง](syntax/strings.md) เป็นหัวใจของการจัดการข้อความ ฯลฯ
- [ทูเพิล](syntax/tuples.md) ช่วยให้ใช้หลายค่าตรงที่คาดว่าจะมีค่าเดียว
- [แมป](syntax/maps.md) เป็นหัวใจของการเก็บข้อมูลปริมาณมาก แต่ถูกนำไปใช้ต่างออกไปพอสมควรใน `Whamm`
- นิยาม[ฟังก์ชัน](syntax/functions.md) ใช้ซ้ำโค้ดบางส่วนได้
- [เงื่อนไข](syntax/conditionals.md) คือคำสั่ง if/else/elif ที่ใช้ควบคุมโฟลว์อย่างง่าย
- [ขอบเขตชนิด](syntax/type_bounds.md) ใช้จัดการออปโค้ดที่มีหลายรูปแบบ (polymorphic)
- `Whamm` ยังมีฟีเจอร์ที่ช่วยเสริมความสามารถในการแสดง instrumentation
  - ตัวแปร [Report](syntax/report_vars.md) เป็นหัวใจของการระบายข้อมูลพลวัตที่ instrumentation เก็บรวบรวมระหว่างการรันแอปพลิเคชัน
  - ตัวแปร [Unshared](syntax/unshared_vars.md) ใช้สร้างอินสแตนซ์ของตัวแปรต่อจุดที่แมตช์ของโพรบ โดยค่ายังคงอยู่ข้ามการมาเยือนจุดนั้น
  - ตัวแปร [Shared](syntax/shared_vars.md) ใช้สร้างอินสแตนซ์ของตัวแปรที่ทุกจุดที่แมตช์ของโพรบ_ใช้ร่วมกัน_
  - ตัวแปร [Frame](syntax/frame_vars.md) ใช้สร้างอินสแตนซ์ของตัวแปรที่เก็บไว้บนเฟรมที่ทำงานอยู่ของฟังก์ชัน
- และสุดท้าย [โพรบ](syntax/probes.md) ใช้แสดง instrumentation
- ไวยากรณ์ทั้งหมดนี้ใช้เขียน[สคริปต์](syntax/scripts.md) `Whamm`
